# Invisible Join: выполнение запросов по звёздной схеме через bitmap-индексы

Учебный проект по внутреннему устройству аналитических СУБД: реализация bitmap-based выполнения запросов по звёздной схеме без материализации обычных соединений между таблицами измерений и таблицей фактов.

Реализация разбирает фильтры, применяет их к соответствующим таблицам, переносит совпавшие ключи на таблицу фактов через bitmap-структуры, пересекает полученные bitmap и возвращает только запрошенные столбцы.

## Стек

C# · .NET · bitmap-индексы · собственные Bitmap/RoaringBitmap-структуры · звёздная схема · OLAP/query processing

## Как работает алгоритм

Пайплайн состоит из следующих этапов:

1. разбор списка выходных столбцов и предикатов фильтрации;
2. применение каждого фильтра к исходной таблице и кодирование совпавших ключей в bitmap;
3. перенос совпадений из таблиц измерений в позиции `FactResellerSales` через соответствующие внешние ключи;
4. пересечение bitmap таблицы фактов логической операцией `AND`;
5. выбор требуемых столбцов для строк, оставшихся в итоговом bitmap.

Ключевая логика фильтрации и bitmap-структуры реализованы явно на C#, без делегирования вычислений готовой СУБД.

## Схема данных

Проект работает со звёздной схемой в стиле AdventureWorks: центральная таблица `FactResellerSales` и измерения продуктов, реселлеров, валют, промоакций, территорий продаж, сотрудников и дат.

## Репозиторий

- `InvisibleJoinAlgorythm/Program.cs` — разбор запроса, построение bitmap, перенос фильтров, пересечение и формирование результата;
- `InvisibleJoinAlgorythm.sln` — решение Visual Studio.

## Контекст

Это архивный учебный проект, сфокусированный на структурах данных и механике выполнения аналитических запросов. Схема и формат входных данных намеренно зафиксированы в коде, поэтому проект следует рассматривать как работу по алгоритмам и database internals, а не как универсальный движок запросов.
